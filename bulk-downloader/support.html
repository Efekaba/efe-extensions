Bulk Downloader

Support

Answers to common questions about Bulk Downloader.

Some images on the page are missing from the list

Many sites only load images as you scroll down (lazy loading), so they aren't on the page yet when you click the icon. Scroll to the bottom of the page first, then click the Bulk Downloader icon again to rescan. Very large pages list their first 5,000 items.

Some files failed to download

Click Retry failed: temporary network errors usually succeed the second time. Files can still fail if the link is broken, the site refuses direct downloads (some sites only serve a file to their own pages), or the file is created on the fly by the page's scripts. Videos that play from blob: addresses aren't listed at all, because they can't be downloaded directly. For a file that keeps failing, open it in a tab and save it from there.

Why can't it scan this page?

Chrome doesn't let extensions read its own pages (such as chrome:// settings and the new tab page), the Chrome Web Store, or other extensions. Open a regular website and click the icon there. To scan a file on your computer, open chrome://extensions, click Details on Bulk Downloader, turn on Allow access to file URLs, and click the icon again.

Where are my files saved?

In a folder inside your Downloads folder, named after the site (for example Downloads/example.com/). You can type a different folder name before you click Download. Files with the same name get a number added instead of overwriting each other. Downloads keep going if you close the Bulk Downloader tab.

Why does Chrome say it can "Manage your downloads"?

That's Chrome's wording for the downloads permission, which Bulk Downloader needs to save the files you select. It only downloads files you choose in its list.

Does Bulk Downloader collect my data?

No. It reads a page only when you click its icon, keeps the list in your browser's temporary memory until you close the browser, and sends nothing anywhere: no servers, analytics, ads or trackers. Details are in the privacy policy.
